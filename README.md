# 🚀 Astro Winter Armor II

A modern and responsive product landing page for **Astro Winter Armor II**, built using **HTML and CSS**.

This project focuses mainly on practicing and implementing CSS **Positioning** and **Flexbox** to create a clean, structured and attractive e-commerce product page.

## ✨ Features

- 🧥 Modern winter jacket product page
- 📍 CSS Position property used for element placement
- 🎨 Clean and minimal UI design
- 🛒 Product size and color selection section
- ❤️ Add to Wishlist button
- 🛍️ Add to Bag button
- 📱 Responsive layout
- 🖼️ Product images and feature sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Position

## 📚 What I Practiced

While building this project, I practiced:

- `display: flex`
- `flex-direction`
- `justify-content`
- `align-items`
- `gap`
- `position: relative`
- `position: absolute`
- Creating structured layouts using Flexbox
- Aligning multiple sections and components
- Building an e-commerce style UI

## 🎯 Purpose

The main purpose of this project was to improve my understanding of **CSS positioning and Flexbox** by building a real-world inspired product page instead of only practicing individual properties.
